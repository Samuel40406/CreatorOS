# CreatorOS — MVP

MVP web do produto para creators/influencers.

## O que já funciona
- Dashboard
- Cadastro de campanhas
- Controle básico de entregas
- Financeiro / contas a receber
- Registro manual de métricas de Instagram/TikTok
- Soma automática das views registradas
- Persistência local com localStorage
- Layout responsivo

## O que NÃO está no MVP
- Login/autenticação
- Banco de dados
- Backend
- Pagamentos
- Integração oficial com Instagram/TikTok
- Emissão de NF
- IA
- Multiusuário

## Como testar
Abra `index.html` no navegador.

Para desenvolvimento, também pode usar qualquer servidor estático local, por exemplo:
`python -m http.server 5500`

Depois acesse:
`http://localhost:5500`
